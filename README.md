A single-page e-commerce web application intentionally engineered with real-world functional defects, UI inconsistencies, input validation flaws, and logic edge cases. 

This repository serves as a practical **Manual Software Quality Assurance (QA) portfolio project** demonstrating full-lifecycle test planning, test case execution using formal design techniques, bug logging, and requirements traceability.
